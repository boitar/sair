MitM Dual-Hook 脚本 16MB 大包缓冲 原生参数调节
一键安装
点击一键安装 Surge 模块
手动安装路径
首页 > 修改 > 模块 > 安装新模块
Release 直链地址 (推荐)
https://github.com/boitar/sair/releases/latest/download/sair.sgmodule
GitHub Raw 备用地址
https://raw.githubusercontent.com/boitar/sair/main/sgmodule/sair.sgmodule
参数调节方式
Surge 首页 > 模块 > SAIR > 编辑参数，可直接使用原生表单配置 endpoint、api_key、model 等参数；亦可在代理启动后在 Safari 打开 http://sair.box 进行可视化调节。

全客户端通用 Safari 原生可视化参数控制台

无论使用 Surge、Loon、Stash、Shadowrocket、Quantumult X 还是 Egern，只要启动对应客户端的代理与 MITM 后，直接在 Safari 访问：

http://sair.box
  • 一键预设：支持 OpenAI、DeepSeek、Gemini、Moonshot、Ollama 快速填充。
  • 即时持久化：点击保存立即写入客户端持久化存储（$persistentStore / $prefs / ctx.storage），优先于默认参数生效。
  • 探针测试：内置上游连通性与模型列表探测（/sair/models）。
